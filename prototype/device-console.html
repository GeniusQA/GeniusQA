三、需要后端提供的接口
接口通道说明
POST /app/console/openHTTP建 MCP 常驻会话，返回 session_key + 首屏 snapshot
POST /app/console/snapshotHTTP拉取无障碍树 + 截图（base64 或静态 URL）
POST /app/console/actHTTPpress / fill / swipe / key，返回新 snapshot 与 refs diff
POST /app/console/saveHTTP步骤数组落 AppScriptModel.script（JSON 列，零 DDL）
POST /app/console/closeHTTP释放会话与设备占用
WS /app/console/{key}/wsWebSocket日志流 + AI 思考流 + 设备端主动变更推送
POST /app/console/ai/startHTTP投递 Skill Job 拉起 Claude Code，复用现有 job 表与 SSE
四、前端关键技术决策
截图传输首屏 base64 内联，后续走静态 URL + 时间戳防缓存；避免大 base64 撑爆 WS 帧
坐标映射后端返回真实分辨率 1080×2400，前端按容器宽度等比缩放，点击时反算回设备坐标
refs 生命周期组件内 currentRefs 每次 snapshot 整体替换；步骤录制时立即翻译为选择器，绝不持久化 ref
会话保活WS 心跳 30s；页面 onBeforeUnmount 与 beforeunload 都要调 close，避免设备被占死
并发保护一个设备同时只允许一个 session；列表页显示占用者，冲突时提示强制释放
人机切换手动与 AI 共用同一 session_key，切换只改写权标志，设备状态连续不中断
保存为用例
